## 2. Selected Model Information
* **Task:** Text Classification (Sentiment Analysis)
* **Model Name:** `distilbert-base-uncased-finetuned-sst-2-english`
* **Hugging Face Model Page:** [https://huggingface.co/distilbert/distilbert-base-uncased-finetuned-sst-2-english](https://huggingface.co/distilbert/distilbert-base-uncased-finetuned-sst-2-english)
* **Description:** 
  The `distilbert-base-uncased-finetuned-sst-2-english` model is a distilled version of the BERT base model, fine-tuned on the SST-2 (Stanford Sentiment Treebank) dataset. It retains over 97% of BERT's language understanding capabilities while being 40% smaller and 60% faster during inference. It is specifically designed to classify English text into two sentiment categories: **POSITIVE** or **NEGATIVE**.

## 3. System Overview & Architecture
This project develops and deploys a RESTful Web API using **FastAPI** to serve real-time predictions from the Hugging Face model.

### Project Directory Structure
```text
LAB_2_API_COMPUTATIONAL_THINKING/
├── .gitignore          # Git ignore configuration for virtual environment and cache files
├── requirements.txt    # List of required project dependencies
├── schemas.py          # Pydantic data models (Request, Response, Validation)
├── model.py            # Hugging Face pipeline and model inference wrapper
├── main.py             # Core FastAPI application defining endpoints and lifespan
├── test_api.py         # Automated API testing script using the requests library
└── README.md           # Project documentation and instructions
```

### API Endpoints
| HTTP Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Returns system overview, API description, and available endpoints. |
| `GET` | `/health` | Verifies operational health status and confirms whether the model is loaded in memory. |
| `POST` | `/predict` | Receives English text input, performs sentiment inference, and returns results in structured JSON. |
| `GET` | `/docs` | Interactive Swagger UI documentation automatically generated by FastAPI. |

## 5. Instructions for Running the Application

Start the FastAPI application with `uvicorn`:
```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
Or run directly using Python:
```bash
python main.py
```

* The server will be accessible at: `http://127.0.0.1:8000`  
* Interactive Swagger UI documentation: `http://127.0.0.1:8000/docs`

---

## 6. Instructions for Calling the API & Examples

The API can be interacted with using either the **Interactive Swagger UI (Browser)** or **Command Line (cURL)**.

---

### 6.1. Interactive Testing via Swagger UI (Recommended for Browser)
1. Ensure the API server is running (`uvicorn main:app --reload`).
2. Open your web browser and navigate to: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).
3. Click on the desired endpoint:
   * **`GET /`**: Click **Try it out** → **Execute** to inspect system metadata.
   * **`GET /health`**: Click **Try it out** → **Execute** to verify the model and server readiness.
   * **`POST /predict`**: Click **Try it out**, edit the input JSON payload in the request body, and click **Execute** to receive sentiment classification results.

#### C. Endpoint `POST /predict` (Inference)

#### Case 1: Positive Sentiment Input
* **cURL:**
  ```bash
  curl -X POST "http://127.0.0.1:8000/predict" \
       -H "Content-Type: application/json" \
       -d '{"text": "FastAPI combined with Hugging Face transformers makes deploying machine learning models an absolute delight!"}'
  ```
* **Example Response (HTTP 200 OK):**
  ```json
  {
    "text": "FastAPI combined with Hugging Face transformers makes deploying machine learning models an absolute delight!",
    "label": "POSITIVE",
    "score": 0.9998,
    "inference_time_ms": 42.15
  }
  ```

#### Case 2: Negative Sentiment Input
* **cURL:**
  ```bash
  curl -X POST "http://127.0.0.1:8000/predict" \
       -H "Content-Type: application/json" \
       -d '{"text": "The application kept crashing on startup, the documentation was completely misleading and frustrating."}'
  ```
* **Example Response (HTTP 200 OK):**
  ```json
  {
    "text": "The application kept crashing on startup, the documentation was completely misleading and frustrating.",
    "label": "NEGATIVE",
    "score": 0.9989,
    "inference_time_ms": 38.60
  }
  ```

#### Case 3: Input Validation Error (Empty / Whitespace-only string)
* **cURL:**
  ```bash
  curl -X POST "http://127.0.0.1:8000/predict" \
       -H "Content-Type: application/json" \
       -d '{"text": "   "}'
  ```
* **Example Response (HTTP 422 Unprocessable Entity):**
  ```json
  {
    "detail": [
      {
        "type": "value_error",
        "loc": ["body", "text"],
        "msg": "Value error, The 'text' field cannot be empty or contain only whitespace.",
        "input": "   "
      }
    ]
  }
  ```
